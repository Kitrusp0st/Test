# Kitrion — учебное портфолио (Kodland)

Основано на структуре шаблона [GitKodland/portfolio](https://github.com/GitKodland/portfolio) и реализует задания по подготовке, разработке, тестированию и публикации.

## Быстрый запуск в PyCharm

1. Откройте эту папку как проект.
2. В терминале выполните `python -m pip install -r requirements.txt`.
3. Запустите `python main.py`.
4. Откройте http://127.0.0.1:5000/.

## Готово

- Цветовая палитра: `#121314` фон, `#1D1F20` карточки, `#EDEFEA` основной текст, `#9DA19E` дополнительный текст, `#393C3D` линии.
- Изображение About: `static/img/kitrion-mark.svg` (графический знак вместо личной фотографии; при желании замените на своё фото).
- Тексты о проекте и навыках, страницы About / Skills / Feedback.
- Все четыре кнопки навыков показывают разные существующие GitHub-проекты.
- Форма получает значения `email` и `text` во Flask и записывает в `data/feedback.jsonl`; этот файл исключён из Git через `.gitignore`.
- Проект адаптирован для узкого экрана, кнопки и поля доступны с клавиатуры.

## Что остаётся сделать самостоятельно

- Проверьте тексты и по необходимости замените изображение на собственное. Ссылки на проекты в `main.py` можно заменить.
- Создайте **отдельный** GitHub-репозиторий (например, `Kitrion-Portfolio`) и загрузите файлы из этой папки.
- **Важно**: GitHub — хранилище кода; GitHub Pages **не запускает Flask**. Для размещения работающей формы нужен Python-хостинг (например, Replit или другой сервис с запуском Flask). Не публикуйте `data/feedback.jsonl`: в нём личные адреса.
- Запускайте Flask в `debug=True` только локально. Для публикации отключите debug и настройте серверный запуск.

## Проверка

1. Главная страница открывается и содержит секции About / Skills / Feedback.
2. Четыре навыка показывают соответствующие проекты.
3. Ссылки GitHub ведут на нужные репозитории.
4. Сообщение из формы появляется в `data/feedback.jsonl`.
5. Перезагрузка главной страницы не приводит к ошибке.
